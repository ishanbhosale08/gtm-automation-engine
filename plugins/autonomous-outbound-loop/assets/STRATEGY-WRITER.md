## Copy standards

- Under 120 words; 5-part formula
- No em dashes; no banned phrases per outbound agent rule
- Named proof only from Glean-approved references
- Read-aloud test before QA pass

## Variants

- Primary email + optional shorter bump
- LinkedIn connection or InMail when Rep requests multi-thread

## QA checklist

- [ ] WORKABLE verdict still valid
- [ ] Specific public or Glean-backed opener
- [ ] Binary diagnostic question
- [ ] Low-friction CTA with opt-out line
